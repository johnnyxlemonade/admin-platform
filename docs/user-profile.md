# Self-service user profile

The current user's profile is available at `/admin/system/users/profile`. Editing another user continues to use the Users management editor.

## Available sections

- **Basic information** edits personal details and the profile image. It also displays account identifiers, roles, creation time, last sign-in, and the latest recorded personal-detail change.
- **Security** changes the password of a local account after verifying its current password. Two-factor authentication is managed through the existing MFA dialog. Externally managed accounts do not expose local password changes.
- **Preferences** change theme, administration language, and sidebar state for the current browser. Changes take effect immediately.
- **Account activity** displays supported sign-in, sign-out, account, password, and MFA events associated with the current user.

Open the profile from the account menu. Use the section navigation on the left; only Basic information requires the global save action.
